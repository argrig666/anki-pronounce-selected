Pronounce Selected Text (Shift+Alt+C)

Instant, ultra-realistic text-to-speech pronunciation of any highlighted text in Anki upon pressing Shift+Alt+C (or custom shortcut). Powered by Microsoft Azure / Edge Neural voices with automatic language detection.

Features

  • Instant Selection Pronunciation: Highlights any word, phrase, idiom, or full sentence across the Card Reviewer, Note Editor, or Card Browser and pronounces it instantly.
  • Smart Fallback on Non-Selection: When no text is selected, the add-on automatically pronounces a configurable card field (default: ItalianExample). On verb conjugation cards, it intelligently speaks the template-specific example (e.g. Loro example). Set to "" in config if you prefer completely silent behavior on non-selection.
  • Automatic Language Detection: Automatically identifies the language of the selected text on-the-fly and selects the corresponding dedicated native voice (Italian, French, Spanish, German, Russian, English, Portuguese, Japanese, Chinese, and more).
  • Dedicated Native Monolingual Voices: Enforces neural TTS principles by defaulting to native monolingual voices (it-IT-ElsaNeural, fr-FR-DeniseNeural, es-ES-ElviraNeural, de-DE-KatjaNeural, ru-RU-SvetlanaNeural, en-US-JennyNeural) to prevent English phonetic leakage on shared vocabulary.
  • Dynamic SSML Locale Integrity: Synthesizes audio with exact xml:lang root document matching to ensure pristine native intonation.
  • Zero Configuration & Zero API Keys: Works out-of-the-box with no Microsoft account or API key required.
  • Dual DOM & Qt Event Interception: Directly captures key events inside the webview DOM for 100% instant, reliable response on Linux.
  • Instant Local Caching (<1 ms): Synthesizes new words in ~400 ms and caches them locally to disk. Repeat reviews play instantly (<1 ms).
  • Audio Preemption: Rapidly highlighting words cleanly stops any previous playback so the new audio plays immediately.
  • Zero-Restart Live Config: Changes made in Tools → Add-ons → Config apply immediately on-the-fly without needing to restart Anki.
  • Multi-Layout Keyboard Support: Works seamlessly across both English and Russian keyboard layouts (physical key code + Cyrillic layout variants).
  • 100% Standalone: Fully self-contained with bundled dependencies. Does not require any other add-on.

Supported Languages & Dedicated Voices

  • Italian: it-IT-ElsaNeural
  • French: fr-FR-DeniseNeural
  • Spanish: es-ES-ElviraNeural
  • German: de-DE-KatjaNeural
  • Russian: ru-RU-SvetlanaNeural
  • English: en-US-JennyNeural
  • Portuguese: pt-BR-FranciscaNeural
  • Japanese: ja-JP-NanamiNeural
  • Chinese: zh-CN-XiaoxiaoNeural
  • (Plus Ukrainian, Greek, Arabic, Hebrew, and standard languages)

Prerequisites

Ensure mpv is installed on your Linux system:

  • Arch Linux / Omarchy: sudo pacman -S mpv
  • Ubuntu / Debian: sudo apt install mpv
  • Fedora: sudo dnf install mpv

Configuration

In Anki, navigate to Tools → Add-ons → select Pronounce Selected Text → click Config.

{
  "shortcut": "Shift+Alt+C",
  "volume": 140,
  "audio_output": "pipewire,pulse",
  "speed": 1.0,
  "show_tooltip": false,
  "fallback_field": "ItalianExample",
  "debug_log": true
}
